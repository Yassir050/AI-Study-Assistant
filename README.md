# 🤖 AI Study Assistant

AI Study Assistant is a modern educational web application designed to help students learn, understand, and practice their lessons with the help of Artificial Intelligence.

The project is currently focused on building a polished and accessible learning interface before connecting it to a real AI backend.

---

## ✨ Current Features

- 🤖 AI study assistant interface
- 💡 AI answer preview interface
- 📚 Quick study actions
- 📝 Question input with character counter
- 🧹 Clear question
- ⌨️ `Ctrl + Enter` / `Command + Enter` shortcut
- 🌙 Dark mode
- 💾 Saved theme preference
- 🪟 Modern glass-inspired UI
- ✨ Smooth animations and micro-interactions
- 📱 Responsive design
- ♿ Accessible keyboard focus states
- 🛡️ Basic HTML escaping for user input

---

## 🔐 Security

The project is designed with security in mind.

User-generated text is escaped before being inserted into the interface.

AI API keys will **not** be stored in the frontend.

The planned architecture is:

```text
User
  ↓
Frontend
  ↓
Secure Backend
  ↓
AI API
  ↓
Backend
  ↓
Frontend
