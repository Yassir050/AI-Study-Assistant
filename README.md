# 🤖 AI Study Assistant

AI Study Assistant is an educational web application designed to help students understand and practice their lessons using Artificial Intelligence.

## ✨ Planned Features

- 🤖 AI explanations
- 📝 Text summarization
- ❓ Question generation
- 📚 Study assistance
- 🎯 Quiz generation
- 📊 Learning progress

## 🛠️ Planned Technologies

- HTML
- CSS
- JavaScript
- Python
- AI API
- Git & GitHub

## 🎯 Project Goal

The goal of this project is to build a practical AI-powered application while learning how web applications communicate with AI APIs.
